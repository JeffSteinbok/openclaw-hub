# OpenClaw Hub

Mirror repo for selected public OpenClaw source.

This repo now carries copied public plugins, services, and shared libs from the main [`openclaw`](https://github.com/JeffSteinbok/openclaw) repo so content can be edited and synced across repos by simple copy operations.

## Canonical source

- Unless a copied manifest says otherwise, the canonical source still lives in `openclaw`
- Public plugin manifests include source metadata pointing at the canonical repo/path
- Mirrored copies here are intended to be kept in sync manually by copying edits in either direction
