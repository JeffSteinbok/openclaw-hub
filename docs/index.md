# OpenClaw Hub

OpenClaw Hub mirrors selected public source from the main `openclaw` repo.

## How this repo is used

- public plugins, services, and shared libs are copied here from `openclaw`
- copied plugin manifests record the canonical source repo/path
- edits can be synced between repos by copying changed content back and forth
